ProofPR 1.0 = AI PR 初审门禁

它只回答一个问题：
这个 PR 现在值不值得维护者投入人工 review？

它不是给个人项目管理 git 工作树的工具。
它更适合开源维护者、团队 reviewer，以及 AI 生成 PR 变多的仓库。

正式接入只记两步：

1. 安装到仓库
   npx proof-pr@latest init
   生成 .proofpr.yml、GitHub Actions workflow 和 PR 模板；提交后打开 PR 即可看到初审报告。

2. 确认接入正常
   npx proof-pr@latest doctor
   检查 workflow、权限、PR 模板和 Action 版本，并直接给下一步建议。

本地命令只是辅助：
   npx proof-pr@latest check
   发 PR 前模拟一次初审。

   npx proof-pr@latest request
   生成一段可以贴给贡献者的补证请求。

PR 报告会给维护者三件事：
- 结论：可以 review、先补证据，还是高风险先别合并。
- 缺口：测试、复现、截图、变更说明、权限理由。
- 重点：供应链、Workflow、密钥、MCP、敏感路径或改动范围。

如果你只是个人项目，且 PR 都是自己写自己合并，通常不需要它。

想自动修复常见接入问题：
   npx proof-pr@latest doctor --fix

想先体验，不改仓库：
   npx proof-pr@latest demo workflow --locale zh-CN

需要可分享页面：
   npx proof-pr@latest check --format html --output proofpr-report.html

需要本地模拟 PR 描述：
   npx proof-pr@latest check --pr-body-file pr.md

高级命令按需使用：
- npx proof-pr@latest template
- npx proof-pr@latest demo --list
- npx proof-pr@latest request --output proofpr-request.md
- npx proof-pr@latest check --format sarif --output proofpr.sarif
- npx proof-pr@latest benchmark --cases benchmarks/cases
